OOP Concepts Demonstrated in C++ Source Code

College Viva Mapping

All actions in this desktop application run directly on main.exe, which executes these exact C++ Object-Oriented Programming structures:

01

Classes & Objects

Custom data types encapsulating attributes and operations: Medicine, StockItem, Person, Supplier, Alert, Inventory.

02

Inheritance Hierarchy

Reusability through specialization:
• Person → Supplier, Customer
• Medicine → Tablet, Syrup, Injection
• Alert → ExpiryAlert, LowStockAlert

03

Polymorphism & Virtual Functions

Heterogeneous collections: vector<Medicine*> and vector<Alert*> call overridden getType(), display(), and serialize() at runtime.

04

Encapsulation & Data Hiding

Internal quantities and prices are protected. State modifications require validated methods like setQuantity(), isExpired(), and isLowStock().

05

Pure Virtual Functions (= 0)

Abstract Base Classes define required interfaces that all derived formulations must implement (e.g. dosage directions).

06

3-File Normalized Storage

Separates catalog specifications from shelf batches (3NF), persisted with C++ streams (ifstream / ofstream).
